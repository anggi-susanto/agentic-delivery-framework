# Scope handshake

Before an agent changes High-risk or Escalation production files, it must return an approval packet. This binds the implementation to an exact outcome and makes scope expansion visible.

```text
DELIVERY IMPLEMENTATION APPROVAL
Task:
Risk lane:
Objective:
Allowed files:
Frozen invariants:
Out of scope:
Adopted/adapted components:
Required RED tests:
Acceptance commands:
Final reviewer route:
No files changed: true
Commit allowed now: no
```

A new file, dependency, migration, or external integration outside the approved scope needs an explicit amendment. If the amendment introduces an independent risk center, split or re-anchor rather than quietly widening the task.
