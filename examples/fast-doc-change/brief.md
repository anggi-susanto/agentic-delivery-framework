# Fast task example

- **Task:** Correct the project URL in the README.
- **Outcome:** The README links to the canonical repository URL.
- **Exact allowed paths:** `README.md`
- **Out of scope:** application code, dependency files, release configuration.
- **Why Fast lane applies:** documentation only; no runtime boundary is owned.
- **Focused checks:** Markdown link check or manual inspection.
- **Final reviewer:** independent reviewer inspects the staged README diff.
